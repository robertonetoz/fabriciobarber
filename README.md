# Fabrício Pereira Barber Club

Site da barbearia Fabrício Pereira Barber Club (Araguari – MG), feito com Next.js, Tailwind CSS e Motion.

- Serviços, equipe, galeria de trabalhos, curso Fast Barber's, avaliações do Google e unidades com mapa
- Agendamento que monta a mensagem pronta e abre o WhatsApp da unidade escolhida
- Animações ao rolar a página, respeitando quem prefere menos movimento

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Editar conteúdo

Textos, horários, telefones, equipe e fotos ficam em `src/data/site.ts`.
As fotos vão em `public/images/` (trabalhos em `public/images/trabalhos/`).
